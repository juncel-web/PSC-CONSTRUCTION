# PSC Construction — Weekly Dashboard
**Live construction operations dashboard hosted on GitHub Pages**

## Files
| File | Purpose |
|---|---|
| `index.html` | Public live dashboard |
| `admin.html` | Login portal for Admin + PMs |
| `data.json` | All project data + user accounts |
| `README.md` | This guide |

## URLs
| Page | URL |
|---|---|
| Live Dashboard | https://juncel-web.github.io/PSC-CONSTRUCTION/ |
| Admin / PM Portal | https://juncel-web.github.io/PSC-CONSTRUCTION/admin.html |

## Weekly Update Workflow
1. PMs log in to `admin.html` → update their project data → **Submit Update**
2. Admin logs in → reviews all data → clicks **Save & Download**
3. A `data.json` file downloads → upload it to this GitHub repo to go live
4. Dashboard at `index.html` refreshes automatically
